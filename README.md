# Music Organizer – JavaFX GUI

## Project Description

This project is a simple Music Organizer application developed in Java using BlueJ and JavaFX.

The application displays a list of available music tracks and allows users to select, play, and stop songs.

## Features

- Displays available music tracks using a JavaFX ListView.
- Uses BorderPane to organize the interface.
- Allows users to select and play a specific song.
- Includes Play Music and Stop Music buttons.
- Shows playback status such as Ready, Now playing, and Playback stopped.
- Displays a helpful message when no track is selected.

## Technologies Used

- Java
- JavaFX
- BlueJ
- ArrayList
- JLayer library for MP3 playback

## How to Run

1. Open the MusicOrganizer project in BlueJ.
2. Make sure the audio folder and required libraries are available.
3. Compile the Java classes.
4. Right-click the MusicOrganizerGUI class.
5. Select Run JavaFX Application.
6. Select a song and click Play Music.
7. Click Stop Music to stop playback.
